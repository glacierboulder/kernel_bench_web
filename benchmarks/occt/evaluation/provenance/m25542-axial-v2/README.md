## 选题与校准

先对原题两份 BREP 共同执行 M28195 所用的 31° 与 Z90° 旋转，再试四个预先列出的备用旋转。缺陷版在全部六个姿态上均未满足严格几何判据。四个自然参考构建在全部六个姿态上也未达到完整通过。锁定的 OCCT 7.9.3 在两个首选姿态的体积误差均约 +0.04097，已超过绝对限 0.03。原题已测的径向位移继续作为单独诊断。六个刚体姿态和八个备选轴向放置的逐版筛查结果均见[资格矩阵](qualification.json)。

轴向对照直接读取原题圆柱、圆锥 BREP。只沿共同轴方向平移圆锥，两条轴的横向距离保持 50，再对两输入一起旋转并执行原题 DRAW 的 `bop` 和 `bopcommon`。轴向幅度按原高度 130 的 1/64、1/8、1/2、3/4 预列，上下两个方向分别筛查。以 B/F 的结果依序选取两种角色，再独立复跑并校准错误输出，封存清单后才复评三个模型补丁。筛查没有使用三份终稿的变体得分。

正确体积由水平截面的两圆盘交叠面积沿高积分，并用极坐标竖直柱体积分复核。正确面积由上下截面、可见锥面和柱面求和，另以极坐标圆环及柱面竖向条带复算。两种表达式的结果差均小于 1e−7。见证点从解析输入推导并随姿态运输，分别核对两输入及结果的归属。面积绝对限 0.02，体积绝对限 0.03，点分类容差 1e−7，沿用原独立几何判据。粗、细两档自适应积分用于识别阈值附近的不确定性。另外保留默认 DRAW 面积相对限 1e−4、有效性、实体数、闭壳和质心范围检查。

在两个入选放置上，B、F 各启动两个独立生产进程，同构建同放置的两份输出 BREP 字节一致。F 的新交体均通过独立解析量和所有归属检查。正对照重读的是该合格 F 输出。空交体、整只圆锥、错移正确交体共六个错误输出，固定读取器与注册观察脚本均拒绝。错移保留面积和体积，由空间见证点识别。
