# 增加 OCCT #30354 曲面与实体布尔截面回归基准

曲面和实体的布尔截面本应包含一条短交边。历史父版找到了两个端点，却遗漏了连接它们的边，线长为零。公开脚本复现 `tests/bugs/modalg_7/bug30354` 中的 `bbop r_2 4` 操作，修复版得到一条长约 0.00670288 的边。[原始测试](https://github.com/Open-Cascade-SAS/OCCT/blob/5fe14d0fac01827796c44a07acae1397d1ea1e8e/tests/bugs/modalg_7/bug30354)

父提交为 `dc57476a0e478cd473400be81495083f2233ce12`，修复提交为 `5fe14d0fac01827796c44a07acae1397d1ea1e8e`。上游修改了裁剪边界的二维分类算法，使用有向面积判断多边形朝向。参考补丁取自这两个提交间的生产源码差异。[上游提交](https://github.com/Open-Cascade-SAS/OCCT/commit/5fe14d0fac01827796c44a07acae1397d1ea1e8e)

| 检查点 | 父版 | 修复版 |
| --- | --- | --- |
| 上游原始位置 | 2 个顶点，0 条边，线长 0 | 2 个顶点，1 条边，线长 0.00670288 |
| 单独将曲面沿 X 平移 0.0001 | 2 个顶点，0 条边，线长 0 | 2 个顶点，1 条边，线长 0.00670288 |
| 两个输入绕原点等比放大 1.25 倍 | 2 个顶点，0 条边，线长 0 | 2 个顶点，1 条边，线长 0.00837861 |
| 两张正交的有界平面 | 2 个顶点，1 条边，线长 4 | 2 个顶点，1 条边，线长 4 |

四个检查点都读取截面的有效性、顶点数、边数和总线长。父版的空边集合仍通过形状有效性检查，缺边由拓扑和线长直接检出。[父版日志](natural-B.txt) · [修复版日志](natural-F.txt)

两份附件均来自公开 OCCT 测试数据镜像的固定版本，已逐文件核对 Git blob。镜像列出了官方测试数据和公开工单附件两类来源，未在仓库顶层声明独立数据集许可证。[输入来源和摘要](input-provenance.md)

查重对照题库 main `20515e0`、PR #2 至 #7 和此前正选：未发现同一输入或修复。这里缺失的是裁剪面内本应保留的截边；不是因为支撑曲面之间没有交线。冻结公开命令的读数：[父版](frozen-public-B.json) · [修复版](frozen-public-F.json)。
