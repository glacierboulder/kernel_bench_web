# 新增 OCCT 单题：关闭第二条面上参数曲线后，三维截线退化为两个孤立顶点

同一张裁剪曲面与平面 X=183.6 求截时，默认模式产生长约 0.000510151 的边；只关闭平面一侧的二维曲线（`-n2d2`），自然父版留下两个端点却丢掉中间整条边。这是布尔截交的几何差异，不是运行错误。

| 截面及选项 | B（顶点、边、长度） | F（顶点、边、长度） |
| --- | --- | --- |
| 原例 X=183.60，`-n2d2` | 2、0、0 | 2、1、0.000510151 |
| 左邻 X=183.59，`-n2d2` | 2、0、0 | 2、1、0.000465350 |
| 右邻 X=183.61，`-n2d2` | 2、0、0 | 2、1、0.000557059 |
| 有界矩形与垂直平面，`-n2d2` | 2、1、6 | 2、1、6 |

这些操作的默认模式在 B/F 上均给出该行 F 的长度和拓扑。正式检查既校验非零长度，又核对边和顶点数；长度误差不超过 `max(1e-8, 1e-4 × 期望长度)`，以模型长度单位计。左右邻域改变平面相对曲面的位置，预期截线长度不同；对照要求保留普通裁剪形成的合法边。

**根因与隔离。** B 的 `IntTools_Context::IsValidBlockForFaces` 只有在两侧均有参数曲线时，才检验二维中点是否在面域上；只有一侧可用时，两面都回退到三维点到面的检验。F 按面分别选择二维或三维判据。单独把该函数换到 B，原例和左右邻域都恢复；同提交的 `Extrema_GenExtPS` 单改无效。因此参考补丁仅含前一个函数，不把另一处变更混入判分。
