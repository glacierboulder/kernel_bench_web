# OCCT 25820 · 旋转面与平面的短截边缺失

锁定源码属于 CDL 时期的 OCCT 7.0.0.dev。题库按源码版本头生成 source_id；生成器的兼容适配只作用于构建目录。

[上游修复及三个 DRAW 原例](https://github.com/Open-Cascade-SAS/OCCT/commit/c0e32b3c3)。原脚本以 `bopcurves` 检查面面求交阶段的曲线数和容差。此题通过 `BRepAlgoAPI_Section` 对同一对有界面做布尔截交，再测量结果边数、顶点数、长度和有效性。

| 检查点 | 自然父版 | 自然修复版 |
|---|---|---|
| 第一个切面 | 0 边、2 顶点，长 0 | 1 边、2 顶点，长 0.000024999999941836 |
| 第二个切面 | 0 边、2 顶点，长 0 | 1 边、2 顶点，长 0.000025348669440044 |
| 第三个切面 | 0 边、2 顶点，长 0 | 1 边、2 顶点，长 0.000025348669440044 |
| 两个垂直平面 | 1 边、2 顶点，长 4 | 1 边、2 顶点，长 4 |

三个触发例的形体在两版均能通过有效性检查。按 DRAW 命令的参数独立测量，组边前的面面交线数由 0 变成 1，修复版达到的三维容差分别约为 9.98e-8、9.03e-8 和 9.04e-8。参考补丁保留上游对步进算法和步进线的两处生产代码修改。

公开材料只包含第一个切平面与旋转面，另外两张切平面随隐藏用例提供。[输入数据集](https://github.com/a-betenev/opencascade-dataset/tree/d78a7a9e6de57699261fa03641ec1b5bafac39a1/brep)。各模型摘要、正式离线回执、空目录冷构建及独立应用证明见本题 `evidence/`。
