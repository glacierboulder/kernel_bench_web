# OCCT #30760 两实体求公共部分时因边方向丢失重叠体

两个相交实体的公共体积应与操作数顺序无关。布尔内核从已有边向另一条边附加面上参数曲线时使用了不一致的边与面方向。历史修复在此步骤统一使用 FORWARD 方向。自然父提交为 `9324aa2d0db76088d01531a879d0eb5633d9d0fd`，修复提交为 `78005ffefef5267b11d93a37457d698f60371bd0`。[上游修复](https://github.com/Open-Cascade-SAS/OCCT/commit/78005ffefef5267b11d93a37457d698f60371bd0)

在冻结题面所在目录运行 `DRAWEXE -b -f reproduce.tcl`。脚本读取随题提供的 `bug30760_shapes.brep`，拆出两个实体，执行布尔 Common，输出有效性、实体数、面数和体积。期望一个有效实体、14 个面，体积与 0.000106046 相差不超过 0.00000001。模型的 Git blob 为 `fa7121cfa3e71d55d1ecb1374920b36a0233d34e`，SHA-256 为 `a86678116d67959210a208f853d0abcf12b9e2c68b2c1e79e93b23041c2b38cb`。[固定版本输入](https://github.com/a-betenev/opencascade-dataset/blob/12ec0ea9af6db153903fe0cf57ff5c4f30f66830/brep/bug30760_shapes.brep)
