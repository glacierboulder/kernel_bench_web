## 校准依据

| 新检查 | 正参考来源与结果 | 缺陷版表现 |
| --- | --- | --- |
| M25237 · 斜轴旋转 | 两份原始边一起绕过 (10,2,−1)、方向 (1,2,3) 的轴旋转 31°。从原输入精确圆弧的半径和参数区间计算弧长 0.100001707094，双顺序检查端点和曲线支撑。 | 正序通过，反序得到 0.104821697643，端点偏约 0.00482。 |
| M25237 · 两段圆弧重叠 | 在原输入精确圆的同一参数区间分别取前、后 75%，正确公共弧是中间 50%，长 0.050000853547。 | 两个操作顺序均正确。 |
| M28366 · 平移中心截面 | 原机身与平面共同平移 (17,−13,0)，平面的参数方向保持原来取向。输入网格独立积分面积 332401307.94，F 测得 332402335.25，642 个位置见证全部相符。 | 面积 70354916.15，382 个见证错误，内核报告警告。 |
| M28366 · 法向偏移 | 原机身保持原位，切面移至 Z=+0.001。网格参考面积 332401312.99，F 测得 332402340.34。 | 有效截面，642 个见证全部相符。 |

M25237 沿用弧长绝对误差 1e−6、端点及支撑最大偏差 1.6e−5。半长弧、同长度相邻弧、端点相同的直弦都被拒绝。健康回归上的直弦与正确弧长只差约 5.34e−8，但支撑偏差达 3.17e−5。M28366 沿用相对面积限 1e−4，误差中计入两倍网格收敛漂移。另查拓扑有效性、平面位置与方向、642 个位置分类和布尔警告。空面结果、等面积面内错位、法向错层均被拒绝。法向错层 0.001 保留面积和位置分类，由平面距离检查识别。每个入选用例在 B 与 F 上均由两个独立生产进程确认。几何见证覆盖有限。

在查看终稿扩展成绩前依序筛选了 M28366 的中心截面。共同斜轴旋转 31° 配面内 53° 时，F 面积超限且有警告；共同平移 (17,−13,9) 配 53° 时，F 面积也超限；原位置配 53° 的 F 同样未过。三者都留在诊断记录。入选的 XY 平移保留原几何交面，考察绝对坐标变化。新邻域和旧原例之间有几何关联，不能将六项检查或多份补丁解释成独立的题目样本。
