# 两张曲面截出的短边出现过大的几何误差

[自然父版](https://github.com/Open-Cascade-SAS/OCCT/commit/48a2dd2012acf5d81b5d3721e7852bd82570c817) 与[修复 #29323](https://github.com/Open-Cascade-SAS/OCCT/commit/faaa95cbe7bcf29c33d2bf6ee2355ad8bfaa2c70)。[同提交上游案例 bug28557](https://github.com/Open-Cascade-SAS/OCCT/blob/faaa95cbe7bcf29c33d2bf6ee2355ad8bfaa2c70/tests/bugs/modalg_7/bug28557)明确选取[公开复合体](https://github.com/a-betenev/opencascade-dataset/blob/d78a7a9e6de57699261fa03641ec1b5bafac39a1/brep/bug27615.brep)第 1 和 19 面。这里公开及正式评分均在**不提供手工种子**的实际 `bsection` 结果上检查，不采用仅在底层带种子命令上成立的判据。

| 情形 | B：顶点/边，截线长度，最大容差 | F：同列 |
| --- | --- | --- |
| 原始两面 | 2/1，2.72347，0.726641 | 2/1，1.93162，0.000005000001 |
| 共同平移 (6,-4,3) | 2/0，0，1.76026 | 2/1，1.93162，0.000005000001 |
| 共同绕 Z 轴转 19° | 2/0，0，约 0.0000002 | 2/1，1.93162，0.000005000001 |
| 两个正交有界面 | 2/1，6，约 0.00000015 | 与 B 相同 |

使用模型长度单位。四例都检查两个顶点、一条边、长度绝对误差小于 0.00002 和最大容差小于 0.000006。单看容差会错误放行旋转后没有边的结果。独立的整实体 Common 在 B/F 上原例高精度积分均约 15287.7，不拿默认积分的漂移作另一道题。整实体 Section 及 Common 的最大容差均从约 0.726641 降至 0.000144441。

**机制。** 上游唯一生产源改动在 `IntPatch_WLineTool`：清理步进线采样时不再删掉会令相邻段间距失衡的采样点，以避免逼近样条振荡。上游带种子 `bopcurves` 是额外诊断证据：原例始终一条曲线，报告容差从 2.18675 降至 2.25623e-6。不同于首轮 #21564 的共线截边冗余，本题删点太多导致曲线失真，且正式判据不限制极点数。

两份自然源码、测试和模型已固定。核对最新题库及 25 个 PR head、既有历史清单：该模型仅在全量数据集目录被索引，未发现相同题或材料。复现命令为 `DRAWEXE -b -f reproduce.tcl`。
