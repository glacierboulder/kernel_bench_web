## 登记与校准

`occt-single20-28195-checks@2` 供显式选择，原任务默认使用 v1。v1 的四个检查声明、用例脚本和支持文件均逐字节核对。新增的两个姿态已在前期诊断中公开。独立 API 契约尚未覆盖，`PASS*` 表示当前几何评测面全通过。

两项都从相同的原始 BREP 加载整个复合体，先旋转，再分解并执行 Common。31° 的轴过 (100, 20, −10)，方向为 (1, 2, 3)。90° 绕经过原点的 Z 轴。两个输入须各为一个有效实体并保持原体积。结果须为一个有效实体，体积须同时符合原位交体体积 172189705.92920932 和已验收交体直接刚体变换后的体积，相对限均为 1e−4。

125 个固定点中，17 个应在交内，108 个应在交外。另加 4 个仅在第二操作数内的排除点。每点以 1e−7 分类容差核对两个输入及结果的预期归属。两个直接变换的正参考均通过，六个错误输出均被拒绝。空交体未通过拓扑、体积和交内点检查。误返回第二输入时原 125 点全部吻合，体积和 4 个排除点识别出错误。将正确交体整体错移能保持体积，但会漏掉交内见证点。
