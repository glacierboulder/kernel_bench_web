# 两个有重叠的实体融合后，结果仍保留两个实体

[自然父版](https://github.com/Open-Cascade-SAS/OCCT/commit/fb60181a3a213c25c4c63797f52cf48798532d96) 与[修复 #29711](https://github.com/Open-Cascade-SAS/OCCT/commit/d3578357e3e819c259d2ddd882a5f9932c7c95ee)。本题取该提交实际修改期望值的上游[回归 F5](https://github.com/Open-Cascade-SAS/OCCT/blob/d3578357e3e819c259d2ddd882a5f9932c7c95ee/tests/boolean/bfuse_complex/F5)，不是同提交另行新增、缺公共模型的 General Fuse 脚本。两个原始输入来自 OCCT 官方测试归档，文件、成员路径和 SHA-256 见 `source.json`。

| 情形 | B：线框/面/壳/实体，面积，体积 | F：同列 |
| --- | --- | --- |
| 原始位置 | 17/15/2/2，8636.79，30978.4 | 9/9/1/1，8231.06，30472.5 |
| 共同平移 (6,-4,3) | 17/15/2/2，8636.79，30978.4 | 9/9/1/1，8231.06，30472.5 |
| 共同绕 Z 轴转 19° | 17/15/2/2，8636.79，30978.4 | 9/9/1/1，8231.06，30472.5 |
| 两个部分重叠的盒子 | 14/14/1/1，72，36 | 14/14/1/1，72，36 |

四种情形在两版均通过形体有效性检查；单看有效性会漏掉原例的错误。要求精确拓扑，面积、体积的绝对误差分别小于 0.02、0.12（模型单位的平方、立方）。

**求交根因。** 第一次求交后，参数边段的两个端点可能已认作属于同一张对侧面，而该段与面的公共关系仍未登记。新增的 `ForceInterfEF` 在已知共端点的候选中用几何检验确认近贴面边段，再为融合提供公共块。只移除 F 中该调用，原例及两个邻域都精确退回 B 的两实体、面积和体积；移除同提交邻近的 `RepeatIntersection`，或仅恢复直线/平面触点及平面边界的旧行为，都不使错误回来。参考补丁保留上游生产源码变更；隔离实验说明本例需要哪个步骤，不声称整个提交只改了一处。

**去重。** 固定题库与 25 个 PR head、历史索引及既有问题材料均无同一修复或输入。模型名和 blob 的唯一文本命中是全量数据集目录。与首轮 #27948 或旧题 #29322 的边边重合复查不同，本例关闭的是“边段是否和面共域”的步骤；保留强制边边处理时仍可复现。复现命令为 `DRAWEXE -b -f reproduce.tcl`。
