# OCCT #31655 边面干涉合并两个精确交点

IntTools_BeanFaceIntersector 在得到多个精确交点时分别搜索其参数范围。原有搜索容差可使相邻交点的范围连成一段。该题用可解析的抛物线代替上游复合形体，从布尔数据结构中读取 EF 干涉对应的新顶点与坐标。[上游修复](https://github.com/Open-Cascade-SAS/OCCT/commit/529444be92b1e446aa4006b9e245b7afdcb3a3f8)

原例为 z = x²/100 − 0.005 与 z = 0 的交点，边容差为 0.01。一个邻域沿 X 整体平移 3，另一个把穿越深度改为 0.001，健康对照取 0.05。四例均要求 EF 数据中出现两个携带新顶点的干涉记录，并按解析式检查两个顶点的坐标。原例的 F 还报告一项容差范围内的无新顶点干涉。

B 为 `210914d5626dec2fa4c717702d873d7b9447473a`，F 为 `529444be92b1e446aa4006b9e245b7afdcb3a3f8`。

| 工况 | B 交点 x 坐标 | F 交点 x 坐标 |
| --- | --- | --- |
| 深度 0.005 | +0.707107 | −0.707107，+0.707107 |
| 沿 X 平移 3 | 3.707107 | 2.292893，3.707107 |
| 深度 0.001 | +0.316228 | −0.316228，+0.316228 |
| 对照，深度 0.05 | −2.236068，+2.236068 | −2.236068，+2.236068 |

表中坐标保留六位小数。校验脚本使用原始精度，分别检查新顶点的横坐标以及 y、z 两个分量。
