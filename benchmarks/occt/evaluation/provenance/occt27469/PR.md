# OCCT #27469 边面干涉误报整条共同区间

锁定修复前版本 `a966542b8ac754a6bc3a5fd0c1e6978b363aeb71` 与修复版本 `380748c340357a6758ac40b2d2a0344bf6484270`。修复改动了 IntTools_EdgeFace 的重合判定和 BeanFaceIntersector 的区段搜索步长。[上游修复](https://github.com/Open-Cascade-SAS/OCCT/commit/380748c340357a6758ac40b2d2a0344bf6484270)

本题用一条可解析的 Bézier 边重建重合误判。前段高度很小，边在靠近末端处明显离开矩形所在平面。倒数第二个控制点的抬升高度为 h 时，高度函数为 24h t²³(1−t)，其在开区间内始终为正。求交得到的一维公共边总长度应为零。邻域分别整体平移和把 h 降到 0.01。健康对照设置 h=0，保留长 24 的完整直边。

自然 B 在原例及平移输入上均错误保留长度 24.0013 的边，在降低高度后仍保留整条边。F 三项均得到零条公共边。共面对照的长度在两版均为 24。正式离线复评原例 1/1、邻域 2/2、对照 1/1，冻结摘要为 `6ef5625f78337e13c35b4def31846c847df7a9bedc7ffb452e9349537bb3693f`。

| 工况 | 修复前（公共边数、总长） | 修复后（公共边数、总长） |
| --- | --- | --- |
| 原例，h = 0.1 | 1，24.0013 | 0，0 |
| 两输入共同平移 (10, −2, 4) | 1，24.0013 | 0，0 |
| 降低控制点，h = 0.01 | 1，24 | 0，0 |
| 整条边落在平面，h = 0 | 1，24 | 1，24 |

在冻结题面的目录运行 `DRAWEXE -b -f reproduce.tcl`，用 `nbshapes` 和 `lprops` 核对公共边数和总长度。自然版本记录见 [B](natural-B.txt) 和 [F](natural-F.txt)。
