# 布尔截交在裁剪面边界上保留多余曲线

从 GEN747_nofog.rle 取复合形的前两个直接子形，运行面面布尔截交，开启曲线逼近及两侧参数曲线。父版给出有效的形状，但多保留了一条截边，不能只凭操作成功或结果有效判定正确。

修正内核对截线候选在裁剪面域内外的判定。此例应产生有效截形，包含 2 条不重复的边、3 个不重复的顶点，总长 72.4222 ± 0.01 mm。改变空间原点或交换输入不应改变交集。不要调整输入、修改公差来凑数，或针对模型名称写特例。

在冻结的公开材料目录运行，SOURCE 指向题目锁定的干净 OCCT 源码，BUILD 指向空的可写目录：

```bash
bash public-build.sh "$SOURCE" "$BUILD"
bash public-replay.sh "$BUILD"
```

复现程序打印边数、顶点数、以 mm 计的总长及有效性。退出 0 为满足几何判据，1 为几何不符，2 为输入或构建结果不可用。
