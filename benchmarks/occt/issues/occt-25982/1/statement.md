# 镜像自由曲面进行广义融合时丢失一侧分割面

读取公开模型，复制形体并关于平面 `x=0` 镜像。按拓扑遍历顺序，从原件和镜像件各取第 4 个面，将两个面作为 General Fuse 的参数并构建结果。当前版本只保留一个面，面积约 152.614。

修复面面求交后的布尔分割，使此输入产生 6 个不同的顶点、11 条不同的边、4 个线框和 2 个面，壳和实体均为 0。两面的合计面积应为 306.285，依上游检查采用 1% 相对误差。比较形状时按拓扑身份去重。

公开输入目录包含原始 BREP 与原例 C++ 程序。Linux x86-64 下，在该目录依次运行以下两条命令。第一个参数是待测 OCCT 源码目录，第二个是独立构建目录。

```sh
bash public-build.sh /path/to/occt /tmp/occt-25982-build
bash public-replay.sh /tmp/occt-25982-build
```

冻结快照将公开文件平铺在题面旁，普通题库 checkout 将它们放在题目的 `public/` 子目录内。构建需要 GCC、Ninja、Python 3、GNU binutils、dpkg-deb、xz 与 Tcl 开发头文件。生成依赖和许可证随包提供。
