# OCCT 23985：圆柱面与平面求交漏掉截线

## 需要解决的问题

给定两个 BREP 面 a、b，它们应存在两条截线。错误基线执行 bsection result a b 后得到空的截线结果。请修复相关求交处理，恢复应有的交线，同时保持交线确实位于两面上，不能只构造任意两条边凑数。

## 输入与目标基线

- `bug23985_b1_draw.brep`：第一个面，含圆柱支撑曲面。
- `bug23985_b2_draw.brep`：第二个有界平面。
- `reproduce.tcl`：完整公开复现脚本。

目标是 OCE 0.13，基于 OCCT 6.6.0。准确身份由 `issue.json` 的 `source_id`（`oce013-authoring-b-5434272be3ee`）锁定。应修改该源码，不应换成修复后的新版本规避问题。

## 公开复现的运行方法

在配置好本题锁定基线 DRAW 环境后，进入脚本所在目录运行 `DRAWEXE -b -f reproduce.tcl`。本机模板中的其他新版本 OCCT 不能替代本题基线，否则原始缺陷可能已经消失。

源码仓库中脚本位于 `public/`、附件位于 `public/inputs/`；框架公开工作区会把脚本与附件放在同一目录。公开脚本支持两种布局。下面片段中的 `inputs` 需指向附件目录。


```tcl
pload MODELING
restore [file join $inputs bug23985_b1_draw.brep] a
restore [file join $inputs bug23985_b2_draw.brep] b
bsection result a b
puts [checkshape result]
puts [nbshapes result]
puts [lprops result]
```

## 错误基线的实际表现

错误基线中截线为 0 条边、总长度 0；历史回归期望和本机修复参考均为 2 条边，总长度约 2000。

## 正确行为

返回两条完整截线，其总长度约为 2000 个模型长度单位；结果应有效。边数与长度是公开可观察的回归量，还应检查交线在两个面的支撑关系与覆盖，不能仅凭“长度相同”断言几何相同。

## 修复应保持的性质

1. 恢复两条交线，避免遗漏、重复、截短或偏离输入面。
2. 共同平移或交换输入面顺序后，物理交集应保持一致。
3. 正常圆柱与平面求交仍应正确，例如平面垂直于圆柱轴线时的圆形截线。
4. 不得直接返回固定坐标的两条线段、修改输入容差或评测期望。
