# 相对边的两个圆角恰好相接

对 10×10×10 盒子的 y=0 面上两条平行于 X 轴的边，同时构造半径 5 的圆角。两段圆柱面应恰好相接。要求得到一个有效实体，包含两张圆柱面，原 y=0 平面完全消失。结果体积应为 500+125π，容差 0.0001。

非对称半径 4+6、6+4 同样应成功相接。半径 4.99+4.99 时，两圆角之间应保留原平面上的窄条。对应体积为 1000−10(1−π/4)(r₁²+r₂²)。
