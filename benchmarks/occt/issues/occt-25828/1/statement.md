# 两个复杂形体的截交结果缺少一段曲线

使用公开的 `buc60462a.brep`、`buc60462b.brep`，按给定顺序执行 `BRepAlgoAPI_Section`。开启曲线近似和两侧参数曲线，关闭并行，模糊容差为 0。操作完成且结果拓扑有效，但全部截边的总长度约为 261.262，小于上游参考 264.314 的允许下限。仅检查结果不为空无法发现这段缺失的覆盖。

修复几何内核，使原例结果有效、截边总长相对于 264.314 的误差不超过 1%。该容差来自上游布尔测试公共判据。刚体变换不应使截线缺失，也不能删除属于不同位置的合法截边。不要修改输入、检查程序或上游数值参考。

在 Linux x86-64 上，从本题的公开材料目录运行下列命令。`OCCT_SOURCE` 指向待测源码树；`BUILD` 指向一个新的空目录。使用 GCC、Ninja、Python 3 和包内提供的历史 CDL 生成器，不依赖系统安装的 OCCT。

```bash
bash public-build.sh "$OCCT_SOURCE" "$BUILD"
bash public-replay.sh "$BUILD"
```

程序输出总长度、拓扑计数和合法性。几何未达标时输出 `verdict=FAIL` 并退出 1；通过时输出 `verdict=PASS` 并退出 0。
