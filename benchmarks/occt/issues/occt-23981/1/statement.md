# OCCT 23981：两个截断圆柱面的交线偏离支撑曲面

## 需要解决的问题

附件保存了两个截断圆柱面 s1、s2。执行曲面求交后，错误基线能返回两条曲线，但这些曲线没有同时位于两个输入曲面上；“返回了两条曲线”本身并不代表求交成功。请修复曲面求交，使两条交线与两个支撑曲面一致，并保持有效的参数范围与曲线表示。

## 输入与目标基线

- `bug23981_s1.draw`：第一个截断圆柱面。
- `bug23981_s2.draw`：第二个截断圆柱面。
- `reproduce.tcl`：完整公开复现脚本。

目标是 OCE 0.13，基于 OCCT 6.6.0。准确身份由 `issue.json` 的 `source_id`（`oce013-authoring-b-5434272be3ee`）锁定。应修改该源码，不应换成修复后的新版本规避问题。

## 公开复现的运行方法

在配置好本题锁定基线 DRAW 环境后，进入脚本所在目录运行 `DRAWEXE -b -f reproduce.tcl`。本机模板中的其他新版本 OCCT 不能替代本题基线，否则原始缺陷可能已经消失。

源码仓库中脚本位于 `public/`、附件位于 `public/inputs/`；框架公开工作区会把脚本与附件放在同一目录。公开脚本支持两种布局。下面片段中的 `inputs` 需指向附件目录。


```tcl
pload MODELING
restore [file join $inputs bug23981_s1.draw] s1
restore [file join $inputs bug23981_s2.draw] s2
intersect i s1 s2
puts [xdistcs i_1 s1 0 1 100]
puts [xdistcs i_1 s2 0 1 100]
puts [xdistcs i_2 s1 0 1 100]
puts [xdistcs i_2 s2 0 1 100]
```

## 错误基线的实际表现

本机错误基线返回两条曲线，但对第一支撑面的采样最大偏离约为 61.63 个模型长度单位。修复参考的相同检查落在 1e-5 的误差要求内。

## 正确行为

该附件应得到两条交线。公开脚本在参数 0 到 1 的区间检查曲线到两个曲面的距离；修复后不能只满足曲线条数，还须使交线位于两个截断曲面的有效区域内，保持整个交线的几何语义。

## 修复应保持的性质

1. 两条交线都应属于两个支撑曲面的交集，不能用重复曲线充数。
2. 对共同平移、旋转后的等价输入保持正确；不要依赖曲线排序、文件名或原坐标。
3. 正常平面求交仍应得到正确直线。
4. 不通过增大模型容差、删除交线或伪造距离输出规避问题。
