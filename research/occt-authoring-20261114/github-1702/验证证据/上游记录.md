### Description

`BRepFilletAPI_MakeFillet` with radius 1.3 on two concave edges reports `IsDone()`, but `BRepCheck_Analyzer` rejects the result: a cylindrical fillet face and a B-spline face each have `BRepCheck_SelfIntersectingWire`. Each edge filleted alone gives a valid result. So do slightly different bar radii and fillet radii.

The solid is a plate fused with a round bar:
- plate: x from -20 to 0, z from -1.25 to 1.25. Its two y side faces are drafted 1 degree both ways from z = 0, where they are at y = ±42.5;
- bar: along y with its axis at x = z = 0, trimmed to |y| ≤ 47.9. Its profile is a circle of radius r with two 1 degree drafted flats meeting at (±r/cos 1°, 0).

The two edges are:
- `s_11`: the line where the plate's bottom face meets the bar;
- `s_21`: the arc where the plate's y < 0 side meets the bar, at z > 0.

Found on V8.0.1; not tested on master. The form's version list stops at 7.9, so "latest" below means V8.0.1.

### Expected Behavior

A valid result, as for the neighbouring radii, or `IsDone()` false.

### Actual Behavior

Every input solid is valid. `bar_plate_r1.6.brep`, read back from file, gives the same invalid result.

### Sample Code or DRAW Tcl Script

https://gist.github.com/pentolope/d05cda2d8b479af7e72ae21eb045ffb3

`fillet_bar_plate.py` is pure Python on OCP (`cadquery-ocp-novtk` 8.0.1.1.0). It builds each solid from primitives and writes `bar_plate_r1.5.brep` and `bar_plate_r1.6.brep`. It then prints the table above and the failing faces for the file round trip. The two BREP files are also in the gist.

```
python fillet_bar_plate.py
```

DRAW equivalent, using the BREP files from the gist. This script was not run; no DRAWEXE was available.

```tcl
pload MODELING
# s_11: plate bottom face / bar, line along y at z = -1.25
# s_21: plate side y < 0 / bar, elliptical arc at z > 0

restore bar_plate_r1.5.brep a
explode a e
blend ra a 1.3 a_11 1.3 a_21
checkshape ra

restore bar_plate_r1.6.brep b
explode b e
blend rb b 1.3 b_11 1.3 b_21
checkshape rb
```
