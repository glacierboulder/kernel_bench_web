# OCCT source bundles

All five source bundles are provided in this branch. The OCE bundle for 31850 is stored whole. Four larger bundles are stored as numbered parts.

Run `python restore-source-bundles.py` with Python 3.11 or newer from this directory. It restores the four original files and checks their SHA-256 hashes. The original bundle locations and hashes are in source-bundle-parts.json. These are OCCT source repositories used to prepare source caches for the accompanying benchmark cases.
