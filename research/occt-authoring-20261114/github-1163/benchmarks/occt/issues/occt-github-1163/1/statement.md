# OCCT GitHub 1163：圆角端部求交遇到空边时崩溃

## 需要解决的问题

对附件中的有效 BREP 形状执行半径为 1 的单边圆角时，圆角端部的求交流程在某些内部边未找到的情况下仍继续访问该边，导致进程发生访问冲突。请修复锁定 B 源码，使程序能够安全处理这一情况，同时保持普通圆角和可成功构造的圆角正常工作。

原始上游 issue 报告的是倒角，本题使用同一输入和第 7 条边，独立验证同一段共享的 `ChFi3d_Builder::IntersectMoreCorner` 路径在圆角操作中也会崩溃。题目 B 是从 OCCT 8.0.1 源码构造的派生提交：它恢复了该问题相关的旧空边检查顺序，并非官方原始历史父提交。必须针对锁定 B 修改，不能直接换用新内核。

## 输入与复现

- `chamfer007.brep`：可通过 `BRepCheck_Analyzer` 的输入形状，共 128 条边。
- `reproduce.cpp`：用 `BRepFilletAPI_MakeFillet` 对 `TopExp::MapShapes` 顺序中第 7 条边（索引从 1 开始）添加半径 1 的圆角。第二个参数是文本文件，内容可为 `original`、`translate`、`rotate`、`copy` 或 `box`。编译时链接 OCCT 的 TKFillet、TKPrim、TKBO、TKTopAlgo、TKBRep、TKMath 和 TKernel 等库。

例如，把 `original` 写入 `original.txt` 后，使用与 B 对应的头文件和库编译 `reproduce.cpp`，再执行：

```text
reproduce chamfer007.brep original.txt
```

先确认打印 `INPUT_OK`；B 上调用圆角运算可能导致进程崩溃。执行 `copy` 会先复制输入形状；`box` 在普通盒子上构造圆角，二者是应成功且结果有效的回归对照。

## 期望行为

| 情况 | B 的本机表现 | 修复要求 |
|---|---|---|
| 原始输入 | 圆角计算中发生访问冲突 | 不崩溃；要么返回有效圆角，要么明确地受控报告无法完成 |
| 原输入平移或旋转 | 同样发生访问冲突 | 相同的安全处理要求 |
| 输入复制后再圆角 | 能构造有效结果 | 继续成功，不能为避免崩溃而禁用该类圆角 |
| 普通盒子圆角 | 能构造有效结果 | 继续成功 |

受控失败与成功构造并不相同：本题允许对原始异常拓扑安全失败，并不声称已经解决该模型的所有几何问题。禁止通过跳过所有圆角、伪造输出、依赖文件名或修改测试来通过。
