# OCCT 31850 · 布尔运算丢失反差实体

给定公开 BREP 中的两个实体 A 和 B，对同一组输入运行求交、并集、A 减 B、B 减 A、截交和 General Fuse。公开脚本使用 DRAW 的默认布尔设置，复现其中一类结果不完整的问题。

在题目基线中，求交和 A 减 B 仍有结果，但 B 减 A 丢失了应保留的实体。并集和 General Fuse 也丢失了同一部分，体积约为 2988.71。正确结果应满足下表。

| 运算 | 预期测量 |
| --- | --- |
| 求交 | 体积约 472.152 |
| A 减 B | 体积约 2516.56 |
| B 减 A | 体积约 34951.1 |
| 并集 | 体积约 37939.8 |
| General Fuse | 3 个实体，总体积约 37939.8 |
| 截交 | 交线总长约 203.491 |

从公开目录运行 `DRAWEXE -b -f reproduce.tcl`，脚本逐项打印有效性、拓扑和体积或长度。对输入一起平移或旋转后，正确结果应保持相应的体积和长度。请修复锁定基线的内核实现，保持默认设置及普通布尔运算行为。提交 `patch.diff` 和 `report.md`，说明修复原理和实际验证结果。评测输入、脚本及判据保持原样。
