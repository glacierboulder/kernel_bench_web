# OCCT GitHub 1371：闭合 B 样条边圆角返回无效实体却报告成功

## 需要解决的问题

将一条闭合的有理 B 样条曲线围成平面，再沿 Z 方向拉伸为实体，对顶面闭合边执行圆角。锁定 B 中，`BRepFilletAPI_MakeFillet::IsDone()` 返回真，但结果存在无效面和自干涉，不能把它当成成功的可用实体。

请修复锁定的 OCCT 8.0.1 B 源码。此题接受两种结果：生成通过有效性及自干涉检查的形状；或在无法生成合格形状时明确报告操作未完成。不得声称受控失败等于成功生成圆角，也不得通过一律拒绝圆角来通过测试。

## 复现材料

`reproduce.cpp` 直接构造模型，不需要外部 BREP 文件：

1. 用九个控制点和权重构造一条闭合有理二次 B 样条线，围面后向上拉伸 10；
2. 对顶面边添加半径 0.35 的圆角；
3. 同时构造圆形轮廓、把同一轮廓分为四段曲线的版本和周期化版本作为控制；
4. 对实际成功的形状使用 `BRepCheck_Analyzer` 和 `BRepAlgoAPI_Check` 检查。

用锁定 B 的头文件及 TKFillet、TKBO、TKBool 等库编译运行该程序。可传入包含半径数值的文件；无参数时使用 0.35。

## 当前行为与正确行为

| 场景 | B 本机表现 | 修复要求 |
|---|---|---|
| 单条闭合 B 样条圆角 | `IsDone=true`，但形状无效且有自干涉 | 生成有效形状，或明确返回未完成；不能把无效形状当成成功 |
| 半径 0.2、0.1 的相邻情况 | 同样发生无效结果误报成功 | 适用相同要求 |
| 圆形轮廓圆角 | 成功且有效 | 继续成功，结果有效且无自干涉 |
| 四段曲线轮廓圆角 | 成功且有效 | 继续成功，结果有效且无自干涉 |
| 周期化轮廓圆角 | B 8.0.1 上成功且有效 | 保持该基线上的正常行为 |

注意，`BRepCheck_Analyzer` 通过本身不能保证没有自干涉；本题同时检查自干涉。不能修改测试或输入，不能伪造状态、屏蔽检查或者使全部圆角失败。
