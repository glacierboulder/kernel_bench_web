# 恢复 OCCT 源码

源码包保留 OCCT 8.0.1 的浅历史边界。使用 Git Bash 或 Linux，在空目录运行以下命令。先将源码包复制到当前目录。

    git init occt-source
    git -C occt-source bundle unbundle ../occt1371-source.bundle
    echo b8f597c677811d1f9f4d8a97f5ae2825c0353a42 > occt-source/.git/shallow

按题包的 sources.lock.json 选择 B 提交，执行 git -C occt-source checkout --detach <B提交>。F 的提交见题包来源记录。
