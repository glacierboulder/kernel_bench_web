# Issue #1：d308 检查点的语义修订

范围：只处理B55三题组中M27310的d308原始检查点。#544及其他同学电脑上的实验重做不在本次范围。

## 原检查错在哪里

旧检查要求两条曲线且 `reported_tolerance` 必须落在 `6.9230965382090094e-6 ±10%`。这是“复现历史上报数值”的回归检查，不是几何质量上界。较小的数值不应仅因低于历史下限而被认定为修复失败；同样，上报很小也不能证明交线准确或完整。

旧suite、检查脚本、解析器和历史结果保留原样。新增独立suite `occt-bf-suite-b55-27310-27773-27252-geometry-v2@1`，位于 `evaluation/suites/new/occt-27310-27773-27252/2.json`。该组后续排队使用新版，其余15个检查点保持原定义。

## 新检查点做什么

1. 输出上报容差和旧历史区间，历史区间不再计分；上报值只检查是否有限、非负。
2. 从原始BREP中同一对圆柱面求交，保留每条曲线的范围、起终点和分支数量。
3. 每分支101点，用锁定输入圆柱的解析方程独立计算双侧径向距离，并测量3D曲线与双侧p-curve经曲面映射的一致性。
4. `1e-4`线性拒绝预算继承已有M27310 BREP邻域的support-mapping预算，独立于上报容差。一个超界测点足以证明必要条件违反；所有测点较小不能证明整条曲线或完整覆盖。
5. 端点、裁剪域和完整覆盖的独立参考未获资格校准，因此将其登记为必需的待定条件。必要条件明确违反则FAIL；已测必要条件满足但覆盖证据缺失则INCONCLUSIVE；不授予PASS。

这是修正误判的保守版本，不宣称已经完成issue中提出的完整覆盖验收器。尤其不能把已有F的端点直接当真值，不能用更密采样或总长度代替覆盖证明。
